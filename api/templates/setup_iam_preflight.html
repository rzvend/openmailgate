{{ result.status_hint }}

AWS does not allow creating a third access key for the same IAM user.

Before deleting any key, confirm whether it is still used by another service.

  1. Identify which old access key is no longer needed.
  2. Deactivate the old key first: 
    aws iam update-access-key \
  --user-name <user> \
  --access-key-id AKIA... \
  --status Inactive
  3. Verify that no service breaks by using the deactivated key.
  4. Delete the old key only after confirming it is safe: 
    aws iam delete-access-key \
  --user-name <user> \
  --access-key-id AKIA...
  5. Return to this page and run Check IAM credentials again.

Deleting an access key immediately may break services that still rely on it. Always deactivate first and confirm before deleting.
