# Dovecot — Docker Alpha

Dovecot provides IMAP access to mailboxes. In Docker mode:

- Configuration lives in `docker/dovecot/dovecot.conf`
- Virtual users are stored in `/app/dovecot/users` (volume `dovecot_data`)
- Maildir is shared via volume `app_data` at `/app/data/maildir`
- Users file is generated by `sync-imap-users` in the API container
- IMAP binds to `127.0.0.1:143` by default (`IMAP_BIND`, `IMAP_PORT` env vars)

## Sync Users

```bash
# In Docker (no sudo):
docker compose run --rm api python3 -m worker.mailbox_admin sync-imap-users --apply

# On host (requires sudo):
sudo python3 -m worker.mailbox_admin sync-imap-users --apply
```

## Limitations

- No TLS/STARTTLS in this alpha version. Use tailnet/VPN/reverse proxy for external access.
- User database uses `passwd-file` with SHA512-CRYPT hashes.
- `mail_location` derives from `%n` (username part before @). The users file must set `userdb_mail` correctly for each entry.
